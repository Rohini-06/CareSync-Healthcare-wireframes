# CareSync Healthcare App

## Overview
CareSync is a healthcare mobile application designed to help users manage appointments, medical reports, clinics, and health-related activities.

## Features
- User Authentication
- Appointment Management
- Medical Reports
- Find Clinic
- Profile Management

4. Low-Fidelity Wireframing
